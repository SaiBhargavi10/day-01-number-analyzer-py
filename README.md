# Number Analyzer (Day 1)

A command-line Python application that accepts a list of numbers and
computes key statistical values such as minimum, maximum, sum, and
average while handling invalid inputs gracefully.

## Features
- Accepts numbers separated by spaces or commas
- Ignores invalid inputs safely
- Calculates:
  - Minimum
  - Maximum
  - Sum
  - Average
- Clean and readable CLI output

## Tech Stack
- Python 3

## How to Run
1. Open terminal
2. Navigate to project folder
3. Run:
   ```bash
   python number_analyzer.py
